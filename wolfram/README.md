# FilmGroups for Mathematica

The 275 film groups — 2+1-dimensional space-time symmetry groups of looping,
plane-tiling animations — as interactive Wolfram Language animations. A port
of the [interactive atlas](https://yaroslavvb.github.io/animated-groups-fable/)
to Mathematica, intended for Wolfram Community.

A film group acts on spacetime by `g: (x,t) → (M.x + v, s t + τ)` with `M` a
2×2 point operation (lattice coordinates), `s = ±1` a time direction, and
`v, τ` fractional translations. Each group's pattern is rendered as the orbit
of one animated motif: a chiral vessel that fills once per period (an
injective, rotation-proof phase clock); time-reversed copies drain.

## Files

- `FilmGroups.wl` — the package.
- `FilmGroupsData.wl` — all 275 groups as exact data (auto-generated from
  `../docs/data/catalog.json` by `build-data.wls`; do not edit by hand).
- `FilmGroupsGuide.nb` — the guide notebook (generated by `make-guide.wls`),
  ready to evaluate and to post.
- `tests.wls` — test suite (`wolframscript -f tests.wls`).
- `build-data.wls`, `make-guide.wls` — regeneration scripts.

## Quick start

Put `FilmGroups.wl` and `FilmGroupsData.wl` in one directory, then:

```wl
SetDirectory[NotebookDirectory[]];
Get["FilmGroups.wl"];

FilmGroupAnimation[95]            (* 4₂4₂2, a fourfold time screw  *)
FilmGroupAnimation["g244"]        (* 6₂3₂2, hexagonal time screw   *)
FilmGroupBrowser[]                (* all 275, with a group popup   *)
```

## API

| Function | Description |
| --- | --- |
| `FilmGroupData[]` | catalog of all 275 groups as a `Dataset` |
| `FilmGroupData[g]`, `FilmGroupData[g, prop]` | one entry / one property; `g` is an index 1–275, an ID `"g95"`, or a notation symbol |
| `FilmGroupFrame[g, t]` | one time slice as `Graphics` |
| `FilmGroupFrames[g, n]` | `n` frames spanning one period (for `Export` to GIF/video) |
| `FilmGroupAnimation[g]` | `Manipulate` with a play/pause animator; `SaveDefinitions → True`, so the output works without the package |
| `FilmGroupBrowser[]` | `Manipulate` over the whole catalog (needs the package loaded) |
| `FilmGroupMotif[θ]` | the bare motif clock at internal time θ |
| `VerifyFilmGroup[g]` | exact check of the group axioms for the stored coset representatives |

Frame/animation options: `"Cells"` (window size in lattice translations,
`Automatic` targets ~16 visible motifs), `"MotifScale"`, `"ShowCell"`,
`"Colors"`, `Background`, `ImageSize`, `PlotLabel`; `FilmGroupAnimation` adds
`AnimationRate` (periods/second, default 1/4), `"Label"`, `SaveDefinitions`.

GIF export matching the atlas (40 frames, 4 s/loop):

```wl
Export["g95.gif", FilmGroupFrames[95, 40, ImageSize -> 320],
  "DisplayDurations" -> 0.1, "AnimationRepetitions" -> Infinity]
```

## Correctness

- The stored operations are exact (integer matrices, rational offsets,
  `Sqrt[3]/2` bases); `tests.wls` verifies identity/inverses/closure modulo
  ℤ²×ℤ for all 275 groups in exact arithmetic. On six representative groups
  it additionally checks placement-level frame invariance: applying any group
  element to the set of placed motif copies at time `t` reproduces the
  placements at time `s t + τ`.
- The renderer mirrors `docs/js/renderer.js` / `enumerate/gifs.py`; frames
  rendered by the Python reference and by this package agree pixel-for-pixel
  up to anti-aliasing (mean channel difference ≈ 2/255, zero best-shift).

Tested with Mathematica 14.2 (`wolframscript`); requires 12.0+ for
`RGBColor["#hex"]`.
