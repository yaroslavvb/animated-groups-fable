Watching a clockwork orbit being found

The pattern on the published page — a Brusselator spiral lattice with the symmetry g227 (p3, clockwork symbol r33₁3₂) — is not a recording of a simulation. It is the solution of an equation: find a state and a period such that running the reaction forward for one third of the period and then rotating the plane by 120° puts every molecule back where it started. This page solves that equation in your browser, in JavaScript, and draws every step of the search.

Everything here is the repository's own arithmetic, ported line by line: the six-neighbour triangular Laplacian, the Brusselator right-hand side, the RK4 flow and its timestep rule, the group's index permutations. The search is Newton–GMRES on the twisted shooting equation, with directional derivatives taken by finite differences of the flow — so the one number that really measures the cost is how many times we had to integrate a third of a period.

Cost, honestly: one residual evaluation is one RK4 integration of T/3 (106 steps at the repository's timestep 0.02, 424 right-hand sides on the 36×36 mesh). GMRES needs one such integration per Krylov vector. The Python reference implementation in the repository needs the same number of integrations but runs several times slower on this mesh, because numpy's per-call overhead dominates a 36×36 array.
